Краткое описание приложения

Silent Habit — это мобильное приложение, разрабатываемое на Flutter, предназначенное для формирования и поддержания полезных привычек в спокойном и ненавязчивом формате. В отличие от классических трекеров привычек, приложение не перегружает пользователя постоянными уведомлениями и не создаёт ощущения давления или вины за пропуски.

Приложение решает проблему выгорания и раздражения, с которыми часто сталкиваются пользователи привычных habit-трекеров. Silent Habit фокусируется на осознанности, минимализме и комфорте, позволяя пользователю самостоятельно контролировать свой прогресс.

Приложение создано для студентов, школьников и взрослых пользователей, которые хотят развивать полезные привычки (сон, учеба, физическая активность, режим дня) без стресса и навязчивых напоминаний. Оно подойдёт людям, ценящим простой интерфейс и спокойный пользовательский опыт.
